# Expo 2030 — إصدار التسجيل بدون تحقق بريد

## ما تغير؟
- عند الضغط على **إنشاء الحساب** يرسل Swift بيانات التسجيل إلى `POST /auth/register` في Flask.
- ينشئ Flask حسابًا في SQLite ويعيد `Session` مباشرة، فتُحفظ جلسة الدخول في Keychain ويكمل التطبيق إلى شاشة التخصيص/الصفحة الرئيسية.
- لا يوجد رمز من 6 أرقام، ولا شاشة تحقق أو إعادة إرسال، ولا يحتاج المشروع إعداد SMTP أو فتح برنامج البريد.
- تسجيل الدخول المعتاد باستخدام البريد وكلمة المرور يستمر بالعمل.
- الحسابات القديمة التي لم تؤكد بريدها في نسخة OTP تستطيع الدخول بنفس كلمة المرور؛ لا تُحذف بيانات SQLite.
- **الحقل `is_email_verified=false` مقصود**: الحساب نشط لكننا لا ندعي أننا تحققنا من ملكية عنوان البريد.
- استعادة كلمة المرور عبر البريد غير مفعّلة في هذا الإصدار؛ لا تستخدم بريدًا مزيفًا أو كلمة مرور غير محفوظة.

## التشغيل

1. لا تحذف ملف قاعدة البيانات الأصلي `backend/instance/expo_users.sqlite3`! انقله إلى مجلد `backend/instance/` في النسخة الجديدة قبل التشغيل (انسخ الملف أثناء توقف Flask). 
2. افتح Terminal داخل `backend` وشغّل:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 -m app.main
```

3. افتح `Expo2030.xcodeproj` في Xcode وشغّل iPhone Simulator.
4. سجّل حسابًا جديدًا وانتقل مباشرة دون OTP. أو سجّل دخولك إلى حساب سابق.
5. من مجلد backend افحص البيانات: `sqlite3 instance/expo_users.sqlite3 'SELECT id,name,email,verified FROM users;'`. ظهور `verified=0` **لا يمنع الدخول**، بل يعني فقط أن البريد لم يتم إثبات ملكيته.

## اختبار API عبر Terminal

```bash
curl -i -X POST http://127.0.0.1:8001/auth/register \
  -H 'Content-Type: application/json' \
  -d '{"name":"Demo","email":"demo@example.com","password":"StrongPass123","accepted_terms":true,"marketing_opt_in":false}'
```

متوقع `201` مع بيانات `user` و`access_token`، من دون طلب بريد. جرّب بريدًا مختلفًا عند إعادة الاختبار لأن البريد لا يمكن تسجيله مرتين.

## ملاحظات مهمة

- لا ترسل حسابات حقيقية عبر HTTP خارج جهاز التطوير؛ استخدم HTTPS عند النشر.
- لمنع إنشاء الحساب باستخدام بريد يخص شخصًا آخر قبل النشر العام، يلزم تحقق ملكية البريد أو وسيلة موثوقة بديلة، مع حماية من محاولات الدخول المتكررة واستعادة حساب آمنة.
- الخريطة والتصميم والبيانات التجريبية لم تُعدل.
